# SculptClub social content strategy — diagnosis + rewrite rules

**Written 2026-09-02. Trigger: operator — "the content you make can be way better",
"maybe learn from competition?", "it now feels too much the same".**
They were right. This file is the measurement, the cause, and the fix.

---

## 1. The measurement (not an opinion)

Across all 7 captions in `public/social/*/index.html`:

| motif | posts containing it |
|---|---|
| "eerste sessie/keer gratis" | **7 / 7** |
| "Egelantiersgracht 424" | **7 / 7** |
| "06:00–22:00" | **7 / 7** |
| €12 / €17 price recital | 5 / 7 |
| "geen contract / abonnement / minimum" | 5 / 7 |
| literal phrase "even voelen of het klopt" | 5 / 7 |

Every post ends with the same three-part footer. The opening line changes; nothing else does.

**Performance, same period:** 265 · 251 · 242 · 244 · 248 · 239 views. Likes 0–2.
Comments 0–1. A dead-flat ~250 across six posts.

~250 flat is not "small reach" — it is TikTok showing each post to one test batch and
declining to expand it, six times in a row. The engagement signal is ~zero, so the
algorithm never widens. **This is not a distribution problem to be fixed with more posts.
It is a content problem.**

## 2. The cause

These are **classified ads, not content**. Each post restates the same offer. There is
nothing to learn, feel, or disagree with — so there is nothing to comment on or send to a
friend, and those are the two signals that buy reach.

The footer (address + hours + prices + "eerste sessie gratis") eats ~40% of every caption
with information that belongs **in the bio**, where it is available on every post for free.

Two captions written on 2026-09-02 reproduced this template exactly. The autopilot was
perpetuating the sameness, not just inheriting it.

## 3. What the field says works (researched 2026-09-02, sources at bottom)

- **63% of top-performing videos hook within 3 seconds.** Start with action, not an intro.
- The two highest-performing hook families in fitness: **transformation reveals** (visual
  proof) and **correction hooks** ("you're doing this exercise wrong") — the latter works
  because viewers check themselves against it.
- **Match the hook to viewer skill, not topic**: beginners → identity/confession;
  intermediate → contrarian or question; advanced → number/stat or knowledge gap.
- 7–15 seconds. Rotate hook categories deliberately so the feed never feels samey.
- For local studios specifically: **member stories, trainer features, behind-the-scenes
  personality** convert; polished offer-cards do not.
- Views are the wrong goal. The funnel is **post → trial booking → membership**, and
  studios hit **25–40% trial conversion when follow-up lands within 15 minutes** (WhatsApp).

## 4. 🔴 The finding that matters most

**SculptClub is publishing the wrong half of its own library.**

| published (all offer-recital) | sitting unpublished, no caption |
|---|---|
| studio-leeg, geen-wachtrij, trainer-rental, studio-tour, trainer-arithmetic | **education-squat-mistakes-001** — a correction hook, the #2 performing family |
| | **pt-how-to-choose-001** — knowledge-gap, funnels to intake |
| | **trainer-spotlight-alex-001** — person-led, the format local studios convert on |
| | trainer-commission-math, intake-pitch, open-gym-pitch, trainer-gezina-EN |

The correction/knowledge/person-led content — the kind that actually travels — has been
blocked for weeks behind a missing caption, while the offer-cards ship on schedule.

**Fix the order, not just the copy.** Ship education + trainer-spotlight first.

## 5. Caption rules (binding for every future post)

1. **Kill the footer.** Address, hours and opening times go in the BIO. A caption may
   carry a price *only when the price is the point of that specific post.*
2. **One idea per post.** If the caption states the offer AND the location AND the hours,
   it has no idea.
3. **Never reuse a phrase across posts.** "Even voelen of het klopt" is now used up — 5/7.
   Before publishing, grep the other captions for your closing line.
4. **Rotate the hook family** — never the same family twice running:
   `correction` · `knowledge-gap` · `contrarian` · `person-led` · `behind-the-scenes` ·
   `number/stat` · `confession/identity`
5. **Earn the first 3 seconds.** The first line must work with the sound off and with no
   context. "Wat je precies huurt voor 12 euro per uur" is a product description, not a hook.
6. **One CTA, and prefer WhatsApp** — it is already on the site ("WhatsApp direct — wij
   matchen") and the 15-minute-response window is where trial conversion is actually won.
   A URL in a TikTok caption is not clickable; sending people to a link they cannot tap is
   why offer-posts convert badly here.
7. **Zero fabrication** (unchanged). Verified 2026-09-02 on sculptclub.nl/nl/trainers:
   13 trainers · sessions from €45 · 5.0 on Google · first intake free · Alex, Gezina,
   Hamish and Roberta are current.

## 6. The biggest single lever (not yet actioned)

**Real footage beats rendered cards.** Every current asset is a generated graphic — a
1080×1920 card with text on a photo. The research is unambiguous that transformation
footage, real member stories and behind-the-scenes clips outperform designed cards in this
niche.

Operator noted (2026-09-02) there is **a large library of SculptClub images on the MacBook
Pro, and possibly elsewhere.** That library is likely worth more than any caption rewrite.
Getting it into the repo is the highest-value next content action. Note: that machine is
not co-located with this shell (verified — a different host on the same network), so it
needs either the operator to move it or a session running on that machine.

## 7. What NOT to conclude

Do not read "~250 views" as "TikTok is not worth it". Six posts of one content type is one
experiment, not six. The correct read is that **one format was tested six times and
failed**; the education/person-led formats have never been tested at all.
